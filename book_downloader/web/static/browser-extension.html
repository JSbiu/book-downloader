书页 · 一次安装

在当前浏览器完成搜索与验证

任务继续在书页管理。扩展会新建自己的任务标签页，使用这个浏览器正常加载站点；需要验证时由你手动完成，随后自动继续。不会导航或读取你原来的标签页。

  1. 下载浏览器扩展 ZIP，解压到一个固定文件夹，后续保留该文件夹。
  2. 在 Chrome 地址栏打开 chrome://extensions；Edge 使用 edge://extensions。
  3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压后含有 manifest.json 的文件夹。
  4. 点击浏览器工具栏中的“书页 · 当前浏览器连接”，选择“允许访问小说站点并连接”。打开书页后，右上角会显示“当前浏览器已连接”。

扩展需要站点访问权限才能读取你提交任务的公开页面，不读取或导出 Cookie。登录、验证码和付费内容不会自动处理。书页关闭后，已连接的扩展仍可服务后台任务；关闭浏览器会暂停页面读取，超时后可重试。

后台重启后，请刷新一次书页重新建立连接。任务标签页关闭后，请重试任务。

已安装 1.0.0 的用户更新到 1.0.1：下载新 ZIP 后覆盖原解压文件夹，在 chrome://extensions（Edge 为 edge://extensions）找到本站扩展并点击“重新加载”，再刷新书页。无需另建目录或重新安装。

如果暂时不使用扩展，可在书页“设置 → 高级设置 → 网页访问方式”选择独立 WSL 验证浏览器。字体修复只对新启动的独立浏览器生效。
