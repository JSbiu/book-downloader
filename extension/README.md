# 书页 Chrome 插件 · 工程样机

这是同一个书页插件的工程版本，保留已认可的紧凑找书与书架布局。最低 Chrome 132。插件运行不需要 Python、WSL 服务、localhost 或第二个浏览器连接器。

## 安装与 Key

1. 本机固定安装目录为 `D:\Tools\shuye-renewal-engine`，后续交付直接更新这里。在 `chrome://extensions` 开启开发者模式，首次选择“加载已解压的扩展程序”并选该目录。开发时也可直接加载本仓库 `extension/`。
2. 点击工具栏书页图标，进入完整书页。在右上角“设置”输入自己的 DeepSeek 官方 API Key 并保存。
3. 输入书名、作者或已支持的书籍链接。确切匹配会预选来源；其他情况先展示十条有效候选，点击“更多结果”展开本轮其余候选。选择后“加入书架”只保存书籍，再点击“下载前 3 章”才取得正文。

保持从同一目录加载。**从 0.2.0 首次升级到本版，需要刷新一次书页（F5）**，让新增的更新检查运行。此后打开、返回书页或停留约十五秒时会检查目录中的版本；空闲时自动重载并重新打开书页，保留本机设置与书架。正在搜索、下载、等待本人确认、交付 TXT 或打开详情/设置时延后，不要求手动解压或去扩展管理页重新加载。开发者模式需保持开启。

工程版不读取旧 Python 书架或缓存；ZIP 保留为同一插件的备用安装包。

Key 保存后输入框立即清空，只显示是否已配置；设置可清除 Key，不提供回显。Key 仅由 worker 发送到 DeepSeek 官方搜索接口的认证 header，不进入来源页面、TXT、诊断或安装包。本机扩展存储不是加密保险箱。

## 本轮范围

- 0.4.1 修正作品与来源的身份边界：书名和作者均明确一致时，同一作品的不同来源共用一个书架 Book ID；同名异作者、缺作者或身份冲突时不会自动合并，也不能为现有书切换过去。书架按书名、作者排序；搜索结果按书名连续分组，组内保留既有来源优先级。标题只在确认为同一作品后更新，占位标题或已存在相同标题时可用于初始化/规范化展示；换源不覆盖作品元数据。
- 0.4.1 当前仍有 2 个换源身份回归（切源被错误拒绝、拒绝响应缺少 `code`），不能用这一版验收“其他来源”切换；修复和复验进入 0.4.2。其余身份与既有来源回归 17/19 通过，详细记录见 [焕新计划](../docs/renewal.md)。
- 0.4.0 将入架、下载与更新目录分开。更新目录只读取目录并显示新增章数，不自动下载或导出；下载时按来源章节 URL 复用正文，目录插入、重排不会把旧位置当作同一章。活动下载需先暂停才可更新目录。工程样机下载范围仍是当前目录前 3 章。
- 书籍详情可“本书拉黑此书源”，停止此书当前来源的下载并保留已有内容。拉黑只属于这本书，已登记别名一并生效，同站其他书及已知不同作者的同名书不受影响；详情中可恢复，恢复不会自动访问。当前来源已被拉黑时，不再继续下载或自动交付 TXT；手动导出保留正文时附风险说明。
- “其他书源”始终可从书架详情发起，精确命中也能继续广域搜索。已有定向结果复用后只补一次广域；已取得的广域结果再次查看与刷新不追加调用。换源由用户明确选择，仍是原书架记录，各来源正文和 TXT 范围独立，不自动拼章。未适配候选仍标明尚不支持下载；没有有效替代结果时如实显示。
- 净化只处理已确认的站内广告、页标题和续读提示，包括没有斜杠的页码；抓取、预览和旧缓存重新导出复用规则，书名移除明确的展示尾巴。**净化不修复源站污染、缺字或错章，也不能证明后续正文可用。** 用户已指出某书在 wxdy 的后续内容不可用；早先前三章读取证据不代表该书可用或整站可信。
- 搜索使用现有 DeepSeek 独立 Search API，先检索已有书源：旧版登记的 23txxt、trxs.cc、笔仙阁、69shuba，以及本版接入的 wxdy.cc；无确定匹配时再广域检索。一轮最多两次请求，每次最多 50 条；已有书源结果优先，只有真正接入下载的来源才启用下载按钮。
- 排除指定起点/QQ 阅读域名（含 `xiaoshuo.qq.com`）及已识别的帖子、资讯、推广。未知站点不能仅凭域名、`book` 路径或“目录”字样放行，需作者与章节/连载/字数等作品信息组合。书名匹配忽略章节标题部分，清理明确展示尾巴；正文/推荐语提及不当作书名。不同作品和未知 URL 身份保留。
- 筛选后的全部候选保留在当前浏览器搜索会话中，首屏十条，展开、收起、返回与刷新页面复用结果，不追加搜索请求；主动重新搜索才发请求。不足十条如实显示，原始 50 条不代表有 50 本相关作品或可下载来源。
- 已适配表示有来源规则；开始下载后检查页面与分页结构，但不能据此证明正文没有污染。未适配候选会保留并标明尚不支持下载。搜索不逐个打开来源页；粘贴书籍链接不调用搜索 API。
- 新插件当前接入 23txxt 与 wxdy.cc 的目录和正文读取；trxs、笔仙阁、69shuba 优先发现但下载仍待迁移。wxdy 已从空扩展缓存完成真实前三章与 TXT 核对：目录两页 179 项，前三章分别六、六、四页。目录按页连续读取，正文按同章网址跟进续页，不受“下一章”的误标影响。
- **工程样机仅取得目录内前 3 个已识别章节。** 正文分页收齐后与断点一起提交，完成后自动交付 TXT。文件明确记录实际范围，不能当作整本下载成功。
- 可暂停、继续和导出已保存正文。Chrome 重启后保留待继续；浏览器运行、来源页可读时，关闭书页界面仍可继续并交付文件。来源页被关闭、改导航或访问受阻时保留当前书籍与已提交内容。
- 只有真实来源提示需要本人确认时，点击“前往来源确认”处理。插件不点击验证码或浏览器安全提示。

实际交付状态及真实来源验收证据见 [焕新计划](../docs/renewal.md)。旧交互原型仍在 `prototypes/renewal/`，其中进度是模拟；本工程版本的目录与正文由来源页读取。

## 开发验证与凭据边界

以下是开发工具，不是插件运行依赖。真实 Key 不得由 Agent 读取、回显、检查前缀/长度/hash、传给协作者或写入日志。真实请求只允许验证程序在进程内使用。

用户在 PowerShell 执行一次不回显输入：

```powershell
wsl.exe -d Ubuntu-22.04 --cd /home/jason/projects/book-downloader --exec /home/jason/projects/book-downloader/.venv/bin/python /home/jason/projects/book-downloader/scripts/renewal-key.py
```

程序写入已忽略的 `.local/renewal/credentials/deepseek.key`，权限 0600。Agent 不打开该文件；验证程序在进程内使用，输出只有状态、数量和完整性结果。共享响应样本只保留中性标题、摘要和链接。`--source-only --source-url <已接入的书籍链接>` 可独立验来源，不读 Key 或调用搜索。真实浏览器验证在后台最小化的临时 Chrome 内完成；离线回归无界面，不接管用户日常浏览器。

离线验证在 Ubuntu 项目终端执行：

```bash
node tests/renewal/search.test.mjs
.venv/bin/python tests/renewal/test_engine.py
```

搜索离线入口固定使用不可回落真实服务的替身，包含真实响应的中性结构回放。浏览器测试只用临时 profile、固定临时下载目录、虚拟 Key 和本机夹具，禁止外部网络。开发人员的 CDP 操作只用于隔离验收，不随插件运行。
