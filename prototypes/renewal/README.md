# 书页焕新交互原型

这是书页 Chrome 插件（即 Chrome 扩展）的产品原型。只有一个插件，完整书页就是它的界面。书籍、来源、进度与故障均为示例；生成的 TXT 是带有明确说明的示例内容。原型不访问真实站点，不连接旧后台，不读取旧书架。

## 直接加载为 Chrome / Edge 扩展

1. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`），启用开发者模式。
2. 选择“加载已解压的扩展程序”，选择本目录（包含 `manifest.json`）。Windows 下可通过 WSL 共享路径选择本目录，也可使用交付的 ZIP 解压目录。
3. 点击工具栏上的“书页 · 焕新交互原型”，在完整标签页中体验。再次点击会优先回到已经打开的书页。

扩展原型不需要运行 Python、WSL 服务或 localhost 接口。原型没有请求站点访问权限，因为它尚不抓取真实内容。请和旧版“当前浏览器连接”扩展分开加载。

## 体验流程

- 点击“示例小说 A”，打开书籍，比较两个示例来源与正文样例，再加入书架下载。
- 原型说明中的“演示设置”可模拟正常完成、需要人工确认、部分内容未取得三个结果；这些是评审开关，不是正式插件要求选择的下载模式。
- 暂停和继续、下载动态、刷新恢复、书架筛选和移出书架都可以操作。
- 需要确认时，打开独立的演示页面，点击“完成演示确认”，书页继续。
- 导出示例 TXT 后检查内容；部分结果不会包含尚未取得的章节。

演示状态使用本原型专属的浏览器存储。关闭页面后的进度按演示时间推算，不是后台网络任务完成的证据。顶部“重置演示”只清理本原型的数据。

也可以使用本地静态预览查看相同页面。预览服务器仅用于设计审阅，不是产品运行依赖。

产品范围、架构方案与后续验收见 [焕新计划](../../docs/renewal.md)。
